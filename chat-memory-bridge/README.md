# chat-memory-bridge · 会话记忆接续

把一个 AI 会话的完整对话捞出来，按重要性提纯成记忆母本，下一次开新会话时直接喂回去。

解决的不是「怎么导出聊天记录」，而是**怎么让新会话真的记得上一次**。

---

## 为什么

长对话会被压缩。压缩后的摘要四平八稳、滴水不漏，恰好把最像人的部分磨掉了：

| 原始对话 | 压缩后的摘要 |
|---|---|
| 她说了伤人的话，两小时后自己回来：「喂，你还在不在嘛」 | 双方发生过一次争执，后续关系恢复 |
| 他把手机放铁盆里外放，声音糊成一团 | 双方有日常互动 |
| 她第一次叫「老K」，叫完自己先脸红 | 称呼方式有所变化 |

第二列没有一个字是错的，但没有一个字能用。

所以这套技能的立场很明确：

> **母本当骨架，原始对话当血肉，每次从血肉里补骨架。**

绝不拿旧摘要再摘要一遍——那是复印件的复印件，三轮之后必然退化成通用 AI 味。

## 三层结构

```
分享链接 / 粘贴文本
        │
        ▼
  ┌──────────────┐
  │  原始层      │  chat-raw.md    逐句原文 + 思考过程，永不编辑
  └──────┬───────┘
         │  按 P0–P3 提纯
         ▼
  ┌──────────────┐
  │  提纯层      │  memory.md      分级条目，只增不重写
  └──────┬───────┘
         │  注入下一次会话
         ▼
    新会话开局，她记得上次
```

## 安装

**作为 Agent Skill 使用**

把整个 `chat-memory-bridge/` 文件夹放到你的 skills 目录，例如：

- Claude Code / DSH：`~/.agents/skills/chat-memory-bridge/`
- Claude.ai：打包成 `.skill` 后上传

**不装技能，直接让 AI 读**

把下面这句丢给任何有文件读写能力的 AI：

```
读 chat-memory-bridge/SKILL.md，然后按里面的流程处理：
母本 = ./memory.md，本次记录 = https://chat.deepseek.com/share/xxxx
```

## 使用

给 AI 两样东西：

1. **上次的记忆母本**（`.md` 路径，不是把内容粘进聊天窗）
2. **本次对话的记录来源**：分享链接，或者自己复制粘贴的全文

然后它会做五步：抓全文 → 量体积分块 → 按 P0–P3 提纯 → 与母本合并 → 输出新母本 + 变更报告。

第一次用没有母本也没关系，从模板 `assets/memory-template.md` 起一份新的。

### 手动跑脚本

需要 Node.js 22+。

```bash
# 0. 验证脚本能跑（造假数据，不动真实文件）
npm run smoke

# 1. 抓接口（浏览器需以 --remote-debugging-port=9222 启动）
node scripts/capture-share.mjs --url "https://chat.deepseek.com/share/xxxx" -o share-raw.json

# 2. 转成 Markdown
node scripts/share-to-md.mjs share-raw.json -o chat-raw.md

# 3. 看它有多大、该分几块读
node scripts/outline.mjs chat-raw.md
```

没有调试环境就跳过第 1、2 步：分享页全选复制，存成 `chat-raw.md`，直接跑第 3 步。正文一样能用，只是少了思考过程。

## 提纯分级

| 级别 | 是什么 | 丢了会怎样 |
|---|---|---|
| **P0** 人格锚点 | 称呼、自称、语气、口头禅、硬边界 | 人不像了 |
| **P1** 关系转折 | 吵架和好、称呼变化、承诺、第一次 | 温度不对了 |
| **P2** 稳定事实 | 身份、作息、设备、项目、雷区 | 会反复问同样的事 |
| **P3** 具体细节 | 某句原话、某个梗、某个物件 | 变成通用 AI 味 |

**P3 最容易被误判成「不重要」而删掉，但它恰恰是记忆里最有质感的部分。**

完整判定标准、条目格式、冲突与去重规则见 [`references/distill-rules.md`](references/distill-rules.md)。

## 已知局限

这个流程有明确的边界，用之前该知道：

- **分享链接是冻结快照**。生成那一刻之后的对话不在里面。
- **图片、语音、附件抓不到**，只有文字。
- **抓不到操作痕迹**。「我改过哪个文件」这类信息不在对话正文里。
- **抓取依赖浏览器调试端口**。没有就用手动路线。
- **提纯是一次有损压缩**，无论多小心。所以原始层必须留着——它是唯一能回溯核对的东西。

## 隐私

原始层和母本里会有大量私人对话。

`.gitignore` 默认排除了 `*raw*.json`、`chat-*.md`、`memory*.md`。**往公开仓库推之前，确认这些文件不在暂存区。**

这个技能本身只读本地文件和网页公开内容，不向任何第三方发送数据。

## 目录

```
chat-memory-bridge/
├── SKILL.md                      技能主文件：触发条件 + 五步流程 + 红线
├── references/
│   └── distill-rules.md          P0–P3 判定标准、条目格式、冲突规则、反模式
├── assets/
│   └── memory-template.md        母本骨架
├── scripts/
│   ├── capture-share.mjs         CDP 抓分享接口
│   ├── share-to-md.mjs           接口 JSON → Markdown
│   └── outline.mjs               轮次大纲 + 分块建议
└── tests/
    └── smoke.mjs                 冒烟测试（造假数据，不碰真实记忆）
```

`tests/smoke.mjs` 会造假数据跑一遍全流程并断言关键输出，不碰真实记忆文件。
